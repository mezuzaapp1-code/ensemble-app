Founder’s playbook

New or rotated API key on Railway: open your project → select the running service → Variables → add or edit the variable name (OPENAI_API_KEY, GEMINI_KEY, or ANTHROPIC_API_KEY) → paste the new secret → redeploy so the container reloads env.

Railway API token (Cloud Infrastructure Cost): open railway.com/account/tokens → create an Account or Workspace token → add it as RAILWAY_TOKEN or RAILWAY_API_KEY in service Variables (never commit it). Optional: RAILWAY_WORKSPACE_ID, RAILWAY_PROJECT_ID, RAILWAY_CREDITS_REMAINING_HINT_USD to mirror credits from the billing UI.
